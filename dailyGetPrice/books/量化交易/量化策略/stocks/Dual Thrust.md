Dual Thrust 日线策略（A股适配版）
=============================

策略概述
--------

Dual Thrust 由 Michael Chalek 在 20 世纪 80 年代开发，是一个经典的趋势跟踪系统。原版为日内双向交易策略，此处适配为 **A股日线级别、只做多** 的版本。

核心思想：根据前 N 日的价格波动范围（Range），在当日开盘价上下设置突破阈值，价格突破上轨时买入，跌破下轨时卖出平仓。

与原版的差异
------------

| 项目 | 原版 | A股日线版 |
| --- | --- | --- |
| 交易方向 | 双向（做多+做空） | 只做多 |
| 交易周期 | 日内（盘中即时开平） | 日线（收盘信号，次日操作） |
| 做空信号 | 跌破下轨开空 | 跌破下轨平多仓 |
| 反转交易 | 可日内反转 | 不可（T+1限制） |
| 信号时点 | 盘中实时 | 收盘后计算，次日开盘执行 |

信号计算
--------

每个交易日收盘后，计算次日交易信号。

### 输入数据

取前 N 日（不含当日）的日线数据：

```
HH = N日最高价的最高价
HC = N日收盘价的最高价
LC = N日收盘价的最低价
LL = N日最低价的最低价
```

### Range 计算

```
Range = Max(HH - LC, HC - LL)
```

HH-LC 衡量"极端高点到收盘低点"的距离，HC-LL 衡量"收盘高点到极端低点"的距离，取较大者确保 Range 覆盖主要波动区间。

### 上下轨

```
上轨 = 当日开盘价 + K1 × Range    （买入信号线）
下轨 = 当日开盘价 - K2 × Range    （卖出信号线）
```

K1、K2 为系数，取值范围 (0, 1]。K1 越小买入门槛越高，K2 越小卖出门槛越低。

交易规则
--------

### 入场

- 无持仓时，当日收盘价 > 上轨 → 次日开盘买入

### 出场

- 持有多仓时，当日收盘价 < 下轨 → 次日开盘卖出平仓

### 不操作

- 收盘价介于上下轨之间 → 维持当前仓位

参数设计
--------

### N（回溯天数）

默认 4。Dual Thrust 原版常用 4~5 日。N 越小对近期波动越敏感，N 越大信号越稳定但滞后。

### K1（上轨系数）

默认 0.5。K1 越大上轨越高，买入条件越宽松，交易频率上升但假突破增多。K1 越小则只捕捉强趋势突破。

### K2（下轨系数）

默认 0.5。K2 越大下轨越低，止损越宽松，持仓时间更长但回撤更大。K2 越小止损越紧，保护利润但容易被震出。

### 参数组合建议

| 风格 | N | K1 | K2 | 特点 |
| --- | --- | --- | --- | --- |
| 保守 | 5 | 0.3 | 0.7 | 买入门槛高，止损宽松，持仓久 |
| 均衡 | 4 | 0.5 | 0.5 | 买卖对称，中等频率 |
| 激进 | 3 | 0.7 | 0.3 | 买入门槛低，止损紧，交易频繁 |

K1 < K2 时策略偏保守（买入难、卖出易），K1 > K2 时偏激进（买入易、卖出难）。

仓位管理
--------

每次交易固定仓位或按以下方式计算：

```
单次仓位 = 总资金 × 风险比例 / (K1 × Range × 合约乘数)
```

风险比例建议 1%~2%，即单笔亏损不超过总资金的 1%~2%。

A股无杠杆，合约乘数为 1，简化为：

```
单次仓位股数 = 总资金 × 风险比例 / (K1 × Range)
```

风险控制
--------

### 1. 下轨止损

跌破下轨即平仓，这是策略内建的止损机制。

### 2. 最大持仓周期

连续持仓超过 M 个交易日（建议 20）且未触及上下轨 → 强制平仓。避免长期横盘锁住资金。

### 3. 涨跌停限制

A股有 10%/20% 涨跌停板，次日开盘可能无法按计划价格成交。若次日涨停无法买入则放弃，跌停无法卖出则顺延。

策略优缺点
----------

### 优点

- 逻辑简单，参数少，易于理解和实现
- Range 动态适应市场波动，震荡期自动收窄通道，趋势期自动放开
- 上下轨系数可独立调节，灵活控制买卖偏好
- 适合趋势行情，能捕捉中线波段

### 缺点

- 震荡市中频繁假突破，反复止损
- 日线级别信号滞后，入场点不如日内版精确
- A股 T+1 限制下无法日内止损，隔夜风险不可控
- 开盘价跳空时上下轨可能失真

与其他策略对比
--------------

| 对比项 | Dual Thrust | 海龟（唐奇安通道） |
| --- | --- | --- |
| 信号基准 | 当日开盘价 + Range | N日最高/最低价 |
| 波动度量 | 动态 Range（高低-收收） | 固定通道（N日极值） |
| 适应性 | 震荡期自动收窄 | 通道宽度恒定 |
| 参数 | N, K1, K2 | 入场周期, 出场周期 |
| 止损 | 下轨（与 Range 挂钩） | 固定 2N 或反向突破 |

Dual Thrust 的 Range 随近期波动自动调整，在震荡期上下轨收窄减少交易，趋势期轨道放大跟随行情，这是它相对于固定通道策略的主要优势。
